# Pinkbox — план и фактическая проверка

Редакция 13 октября 2026. Пользователь согласовал новую клавиатурную концепцию, четыре additive loops и поручил реализовать/опубликовать без дополнительных вопросов. Эта редакция заменяет прежние планы генератора и двух источников на роль; исторические планы/измерения сохраняются в Git, но не выдаются за проверку новой версии.

## Уточнение после авторской проверки

Автор принял инструмент и запросил четыре дорожки, шесть тембров, более громкий/мягкий бас, отсутствие scroll при ширине 1502 на 100% zoom и сокращение подписей по приложенному скриншоту.

- Лимит уменьшен до четырёх, аудиограф — пять каналов с live. Сначала падавшие тесты на лимит/шесть тембров прошли после изменений.
- Добавлены PLUCK, ORGAN, AIR; первые SOFT/GLASS/ANALOG сохранены. Все шесть проверены по реально звучащему сигналу и доступны в REC.
- Бас: тёплый custom waveform, attack 18 ms, sustain 0.82, −12 dB. Сравнение с прежним preset в том же настоящем инструменте показало примерно трёхкратное увеличение RMS сигнала; это измерение уровня, не обещание трёхкратной субъективной громкости.
- Повторные/русские visible captions убраны. LINK/MANUAL, CHORD/ARP/TONE/FILTER, короткие имена записей; направление ARP доступно через ···, BPM остаётся. Декоративная звезда — монохромный SVG, чтобы цветная emoji не подменяла чёрный знак с референса.
- Viewport проверен на 1502×640 и 1502×700 при 100% zoom, включая активный REC. Accessibility и общий browser flow повторены.

## Фактические проверки

- `bun install --frozen-lockfile`: без изменения зависимостей/lockfile.
- `bun test`: **18 pass, 0 fail, 629 assertions**. Тесты прежнего случайного генератора заменены проверками новой модели, а не оставлены с устаревшими ожиданиями. Проверяются гаммы, белые/чёрные аккорды, надстройки, удержание/приоритет, bass modes, REC, note-off, snapshot settings, четыре slots, empty candidate, STOP/reset, BPM и недопустимые данные.
- `bun run check`: JavaScript syntax passed. Linter/TypeScript checker не настроены; они не объявляются пройденными.
- `bun run build`: статичный browser bundle/страница собраны с прежним Tone workaround. Новых runtime/development зависимостей не добавлено; formatter запускался отдельно через Bun x, не входит в приложение.
- `bun run test:browser`: полный пользовательский сценарий пройден. Нажатие клавиши разблокировало звук, удержанный аккорд изменился C minor → D minor; REC записал четыре такта за **7996 ms** браузерного polling при 120 BPM, точная длительность данных — 3072 ticks. После REC live остался звучать, после key-up loop остался слышимым. Проверены ARP, второй clip, LINK bass, manual pad, 9TH, чёрная major-клавиша, четыре настоящие записи, блокировка пятой, volume/mute/delete и новый REC в освобождённый слот.
- Browser audio: четыре записи плюс live, пик 0.153 в проверенном сочетании; пять инструментов. После STOP тишина через 40 ms; после PLAY loops слышны. 15 быстрых запусков/остановок освобождены, подписчик один. Blur release, отмена REC через STOP, RESET всех clips, отсутствие ошибок браузера — успешно.
- Browser geometry: desktop 1502×640, 1502×700, 1280×640, 1512×850, 1280×720 и 1024×768 без вертикального/горизонтального scroll. Mobile 390×844 без горизонтального scroll, вертикальный scroll разрешён.
- `bun run test:accessibility`: минимальный контраст **5.5149:1**, проверено 66 текстовых элементов/контролов; keyboard focus 3 px, draft BPM не перезаписывается clock-перерисовкой.
- `bun run test:sounds`: шесть тембров дали реальный сигнал без ошибок. Новый бас RMS 0.0713 против 0.0236 у прежнего preset в том же инструменте (отношение 3.018). Четыре настоящие басовые записи плюс live, все громкости 100%: пик 0.235, ниже порога 0.95. Музыкальная оценка приятности остаётся слуховой.
- `bun run test:stress`: после четырёх настоящих четырёхтактовых записей выполнено **60 секунд**, 556 измерений; live менял tonic/ARP/timbre/filter и BPM, loop volume менялся отдельно. Пик **0.170**, одна сессия, пять инструментов, один repeat-clock, один UI subscriber. Рост retained heap после GC **2662504 bytes**, меньше 20 MiB. После STOP все сессии освобождены. Это минутная проверка нового движка; пятиминутная прежнего движка не переносится на него.
- Финальный smoke после блокировки неактуальных ручек в BASS: ARP отключён в басе, снова доступен в KEYS; range управляется с клавиатуры, ноутбучная A играет даже после редактирования range. Syntax, unit и build повторены после форматирования.

Артефакты: `/tmp/pinkbox-validation/results.json`, `accessibility.json`, `stress.json`, `desktop.png`. Browser test использует headless desktop Chromium/Linux; аппаратная задержка колонок и реальный MacBook этим не измеряются.

## Что выявлено при проверках

- Статус модели обновляется чуть раньше audible time из-за lookahead; проверка сигнала теперь ждёт реальное звучание, а не считает раннюю нулевую выборку неисправностью.
- Тест отмены REC первоначально пытался нажать заблокированный REC при четырёх slots; исправлен сценарий теста — сначала освободить слот. Ограничение приложения работает как согласовано.
- Дополнительные контролы сделали корпус выше на небольших desktop; компактная раскладка исправлена, geometry-test прошёл.
- Декоративная звезда не проходила строгий контраст; исправлены цвет/доступность, проверка прошла.
- Bass MANUAL должен читать пэды, LINK — клавиатуру; отдельный сначала падающий unit test подтвердил отсутствие маршрутизации, после исправления прошёл.

## Открытая приёмка и будущее

Авторская оценка звучания, удобства и соответствия фотографии остаётся открытой. Safari/реальный MacBook/mobile audio ещё не проверены. Игра квантована на 1/16, возможна ощутимая задержка до следующего шага; более свободный live timing — отдельное улучшение после авторской проверки.

Внешний MIDI/FX, два сэмпловых банка и sample start, PCM-export, IndexedDB/восстановление, reverb/delay/swing не реализуются скрытыми заглушками. Продуктовых вопросов, блокирующих выбранную версию, нет; текущие ограничения записаны явно.

Исходная версия остаётся в опубликованной `legacy-pinkbox` на `422b9458e61d6b80286068e97bf3ccacbaf32ddb`; предыдущая версия LIVE/LOOP — коммит `0256ee40c81875889ecaebc49b91f4bf97bfafc1` в истории main.
